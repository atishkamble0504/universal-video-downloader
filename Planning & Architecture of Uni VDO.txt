# Phase 4 — Build Backend API 🔧

## 1. Create Extract API

Endpoint:

```
POST /api/extract
```

Example response:

```
{
title: "Video Title",
thumbnail: "...",
duration: 240,
formats: [
{quality: "360p"},
{quality: "720p"},
{quality: "1080p"}
]
}
```

---

## 2. Create Download API

Endpoint:

```
POST /api/download
```

Workflow:

```
1 receive url + quality
2 send task to queue
3 worker downloads video
4 worker merges streams
5 return download link
```

---

## 3. Worker System

Downloads should run in background.

Queue system:

```
Redis
RQ workers
```

Worker flow:

```
Job received
     ↓
yt-dlp download
     ↓
FFmpeg merge
     ↓
store file
```
